# REALMS Alpha Test Checklist

## Before each match

- Realm
- Player 1 faction / passive
- Player 2 faction / passive
- Who began with Initiative

## During the match

- Did the recurring five-card hand cycle feel like a decision or busywork?
- Did +1/+2 Resource Production create meaningful keep/return choices?
- How often did a player have cards they wanted to play but could not finance?
- Did Placement alternate cleanly?
- Did Combat activation order matter?
- Did either passive feel irrelevant for several rounds?
- Did either Realm effect fail to participate?
- Did a Legendary enter play? If so, did it feel appropriately exceptional?

### Living Geodes
- Round of first Crack
- Dormant Geodes destroyed before cracking
- Largest Kimberlite chain
- Number of useful Fracture triggers

### Continuum
- Highest Sequence reached in a normal round
- Did Sequence 3/4+ happen naturally?
- Did Skip Ahead or Loop Back feel clearly superior?

### Harvest
- Permanent stat snowball size
- Whether deaths felt profitable too often
- Regurgitate vs Consume value

### Moondemons
- Bloodthirst triggers used per round
- Whether fixed 2 HP felt fair
- Frenzied creatures that actually got to defend

### Eliteborn
- How often a linked pair survived meaningful combat
- Whether shared death still feels worth the link reward
- Chain Link overlap with Eliteborn formations on Upper Strata

### Deadlands
- Grave Echo summons
- Enemy cards stolen from shared Grave State
- Repeated reuse of one high-value printed ability
- Echo absorptions
- Whether Echo death → faction trigger felt correct or exploitable
